Public beta · Compatibility & privacy

Clear expectations.
Your Mac stays yours.

Zenith integrates with macOS, media apps, files, audio devices, launchers and games. Here is what the current beta requires, what stays on your Mac, and which tools are still experimental.

System requirements

Zenith 1.3.1 requires an Apple silicon Mac running macOS 26 or later. A physical display notch is optional; floating island mode works on displays without a notch.

Permissions

Features request macOS permissions only when needed: Accessibility/Input Monitoring for gestures and keyboard sound, Automation for Apple Music EQ and browser tabs, Camera for optical presence/hand features, Calendar for schedule views, and audio/screen permissions for visualizers or recording tools.

Privacy & local data

Settings, notes, tasks, clipboard history and saved EQ curves are stored locally on your Mac. The website keyboard and EQ demos run in your browser and never capture or transmit what you type.

Network features

Update checks connect to GitHub Releases. Optional tools—such as lyric lookups, motion artwork, AI usage checks, Aternos status or Play Together—use their respective services when enabled.

Experimental features

Optical recognition is a convenience camera feature and is not Apple Face ID, biometric authentication or a security boundary. Charge limiting, thermal pause, game bridges, call controls and Bluetooth route locks depend on hardware and third-party app support.

Updates & recovery

Zenith includes a signed updater. If an older build cannot complete an update, download the standalone Zenith Updater or install the latest Zenith DMG.
