Know what is included.

Native app integrations require their respective apps and permissions. Travel, sports and delivery layouts need a compatible source of updates. Preview controls do not imply an active service. A standalone iPhone companion, universal Raycast extension execution and a public plugin store are not announced as available in this beta.

More pages. A clearer game view.

Convert large image batches to PDF with page-by-page processing, preserved order and an output folder that opens when ready. Successful conversions remove source entries from the shelf while keeping originals on disk.

Game Mode now has a pinned stats panel with separate CPU and GPU graphs, memory, temperature and power readings. Game-specific tools remain experimental and need supported integrations.
