# Zenith feature directory

**By Harsh Paun · Beta**

[Website](https://techgamewithharsh-dot.github.io/zenith-dynamic-notch/features.html) · [Overview](README.md) · [Beta notes](BETA.md)

Descriptions cover the current user-facing feature set, including experimental and preview experiences. They do not describe the application’s implementation.

- **Beta:** present in the app; behavior can still change.
- **App dependent:** needs compatible apps, hardware, permissions or supplied data.
- **Experimental:** still being validated.
- **Preview:** incomplete or illustrative, not a finished live service.

## The dynamic notch

| Feature | Description | Status |
| --- | --- | --- |
| **Dynamic notch for Mac** | Keep useful controls beside the camera, with compact, expanded and floating presentations. | Beta |
| **Unified liquid glass design** | A shared visual style brings translucent surfaces, rounded panels and coordinated controls across the notch. | Beta |

| **Customizable floating bar** | Choose, remove and reorder the shortcuts beneath the notch with its long-press editor. | Beta |

| **Multiple displays** | Configure a notch, floating island or minimal pill on connected displays, including supported Sidecar displays. | Beta |
| **Multiple activities** | Keep ongoing activities close with compact indicators and satellite bubbles. | Beta |
| **Interactive keynote tour** | Explore live notch panels, lock-screen personalization, the lid effect and permission setup in an interactive introduction. | Beta |

## Availability boundaries

A standalone iPhone companion, universal Raycast extension execution, a public plugin store and automatic integrations with every travel, sports or delivery provider are not announced as available. Feature availability in a distributed DMG should be checked against that release’s notes.
